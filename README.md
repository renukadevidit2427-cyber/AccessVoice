# AccessVoice
An accessible multilingual communication system.
## About
AccessVoice is a web application designed to help users communicate using text and voice in multiple languages.
## Technologies Used
- Python
- Flask
- HTML
- CSS
- JavaScript
## Features
- Multilingual communication
- Voice input and speech output
- Quick message options
- Message history
## How to Run
1. Install Python.
2. Install the required packages.
3. Run `python app.py`.
4. Open `http://127.0.0.1:5000/` in your browser.
